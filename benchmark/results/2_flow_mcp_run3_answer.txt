## Request Chain (ordered)

1. **`POST /arena/attack`** — HTTP request hits **arena-api** (`ArenaController`)
   - Body: `{ weaponType: string }`

2. **`BattleGuard.canActivate()`** — time-based gate check runs before the handler
   - Blocks requests if `hour < 6 || hour >= 22` (Tom sleeps at night)
   - Returns `403` if outside allowed hours

3. **`ArenaController.attack()`** — delegates to `ArenaService.tomAttacksJerry(weaponType)`

4. **`TomClient.getStatus()`** — HTTP GET to **tom-api** → `GET http://tom-api:3001/tom/status`
   - **tom-api**: `TomController.getStatus()` → `TomService.getStatus()` → Prisma query on **tom-api DB**: `Cat.findFirst({ where: { name: 'Tom' }, include: { weapons: true } })`
   - Returns: `{ id, name, health, speed, mood, weapons[] }`

5. **`JerryClient.getStatus()`** — HTTP GET to **jerry-api** → `GET http://jerry-api:3002/jerry/status`
   - **jerry-api**: `JerryController.getStatus()` (wrapped by `TrapInterceptor`) → `JerryService.getStatus()` → Prisma query on **jerry-api DB**: `Mouse.findFirst({ where: { name: 'Jerry' }, include: { traps: true } })`
   - Returns: `{ id, name, health, speed, clever, traps[] }`

6. **`JerryClient.getTraps()`** — HTTP GET to **jerry-api** → `GET http://jerry-api:3002/jerry/traps`
   - **jerry-api**: `JerryService.getTraps()` → Prisma query: `Trap.findMany({ where: { isSet: true } })`
   - Returns: `Trap[]`

7. **Battle logic** — resolved in-memory in `ArenaService`:
   - `activeTrap` found → result = `TRAP_TRIGGERED`, damage = 0
   - `jerry.speed > tom.speed + 20` → result = `JERRY_DODGES`, damage = 0
   - Otherwise → result = `TOM_HITS`, damage = 25

8. **`PrismaService.battleEvent.create()`** — writes to **arena-api DB** (`BattleEvent` table) with `{ tomId, jerryId, weapon, trap, result, damage }`

9. **`BattleResultProducer.publish(event)`** — publishes the `BattleEvent` record to the `battle-results` Kafka topic

10. **Response returned** — `{ ...event, tom: tom.name, jerry: jerry.name }` sent back to caller

## Cross-Service Calls

| From | To | Protocol | Endpoint |
|------|----|----------|----------|
| arena-api | tom-api | HTTP GET | `GET /tom/status` |
| arena-api | jerry-api | HTTP GET | `GET /jerry/status` |
| arena-api | jerry-api | HTTP GET | `GET /jerry/traps` |

All HTTP calls are via native `fetch()`. No circuit breaker or retry logic is present in the code.

## Async Side Effects

**Kafka — `battle-results` topic**
- `BattleResultProducer.publish(event)` publishes after every successful attack
- **spectators-api** consumes this topic via `BattleResultConsumer` (`@EventPattern('battle-results')`)
  - → `SpectatorService.recordBattle(event)` — appends event to an in-memory `battles[]` array

**Note:** `BattleGateway` (WebSocket via socket.io) has a `broadcastBattleResult()` method defined, but it is **not called** from `ArenaService` — there is no wiring between `BattleResultProducer` and `BattleGateway` in the current code. The gateway only handles incoming `watch-battle` socket events.

**`NotificationService`** exists in spectators-api (calls `POST http://notifications:3005/push`) but is **not invoked** from the `battle-results` consumer path — there is no call to it in `BattleResultConsumer` or `SpectatorService.recordBattle()`.

## Data Models Touched

| Service | Model | DB | Operation |
|---------|-------|----|-----------|
| **tom-api** | `Cat` | tom-api PostgreSQL | `findFirst` (read) |
| **tom-api** | `CatWeapon` | tom-api PostgreSQL | included in `Cat` query (read) |
| **jerry-api** | `Mouse` | jerry-api PostgreSQL | `findFirst` (read) |

`BattleEvent` fields written: `tomId`, `jerryId`, `weapon`, `trap` (nullable), `result` (enum: `TOM_HITS` / `JERRY_DODGES` / `TRAP_TRIGGERED` / `MUTUAL_DESTRUCTION`), `damage` (int), `round` (defaults to 1), `createdAt`.
